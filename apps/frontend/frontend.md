# Archive 99 Storefront

The customer-facing application built with **SvelteKit** and **Tailwind CSS**.

## Key Directories

-   **`src/routes/`**: [**pages.md**](./src/routes/pages.md) (File-based routing).
-   **`src/lib/`**: [**lib.md**](./src/lib/lib.md) (Shared Code).
    -   **`components/`**: [**components.md**](./src/lib/components/components.md) (UI Atoms).
    -   **`widget/`**: [**widget.md**](./src/lib/widget/widget.md) (Chat Feature).

## Design
We use a custom "Old Money" aesthetic defined in `src/app.css` and `tailwind.config.js`.
